# 成员指南：打卡与计分

[English](MEMBER_GUIDE.md) | **简体中文**

这里只需要两件事：记录自己的工作与运动，交流彼此的经验。

## 1. 建立一个长期打卡帖

打开[每日打卡表单](https://github.com/Al-LeanMuscle-Club/AI-LeanMuscle-Club/issues/new?template=daily-checkin.yml)，填好时区。默认是 `Asia/Shanghai`，也可以用 `America/Los_Angeles`、`UTC` 等 IANA 时区。

每人一个 Issue，跨周继续使用，保留标题的 `[Check-in]` 前缀。想参加公开周榜时，把 **Public leaderboard** 选成 **Yes**；默认 **No**，不影响在自己的帖子里记录。

## 2. 每天在自己的帖子下评论

```text
/checkin 2026-10-26 W=1 E=0
```

替换成实际日期。`W` 是当天是否工作，`E` 是是否运动，`1` 表示是、`0` 表示否。工作与运动都做了就写 `W=1 E=1`，休息日可以写 `W=0 E=0`。不要求时长、运动项目、照片或身体数据。

一条评论只放一条打卡，打卡写在第一行，不要把代码块的反引号一起粘贴；想补充感受可以另起一行。日期按帖子的时区填写，不记录未来日期。

同一天写了多次，以最新有效评论的两个值为准；编辑旧评论也可以纠正记录。想清除当天的两项记录，可以重新写一条 `W=0 E=0`。删除最新评论后，较早的有效记录可能重新生效。

只有帖主自己的评论计入天数，其他人的回复只作交流。若不慎建了多个打卡帖，使用创建时间最新的那个；关闭它或选 No 不会恢复旧帖。

## 3. 看每周榜单

周一至周日，工作和运动分别按日期去重。周内累计工作天数记为 $W$，运动天数记为 $E$，得分为：

$$
S = 100 \sqrt{\min(W/5, 1) \cdot \min(E/4, 1)}
$$

工作 5 天、运动 4 天分别封顶；任意一项为 0 时，得分为 0。分数保留两位小数，同分并列。

| 工作天数 W | 运动天数 E | 周分数 |
| ---: | ---: | ---: |
| 5 | 4 | 100.00 |
| 5 | 1 | 50.00 |
| 0 | 4 | 0.00 |

这些是计分示例，不是成员记录。分数只反映自报参与，不比较工作时长、运动量或身体状态。[完整规则和更正方式](SCORING.md)

周榜每天北京时间 **09:15** 定时更新，GitHub 有时会延迟。默认刷新本周和上周，可以补记这两周的真实记录；更早的修正可请维护者手动刷新对应周。[周榜与历史](../reports/daily/README.md)

已有的公开 Activity 运动记录，经维护者授权迁移后也可以进入周榜，按原日期计一次运动，不推断工作天数。工作天数为 0 表示尚未登记工作记录，因此最初得分可能是 0。成员或维护者明确提供实际工作或运动日期并授权补记时，也可由维护者补入，并注明信息来源和执行者；补充运动时保留已有日期，只有明确要求纠正才移除。你可以在自己的打卡帖下补记或纠正工作和运动情况，下次统计会更新，同日打卡会替换导入记录的两个状态。迁移说明会注明由哪位维护者开启上榜，你仍可选 No 或关闭打卡帖退出。

## 分享经验与交流

[经验分享](https://github.com/Al-LeanMuscle-Club/AI-LeanMuscle-Club/issues/new?template=experience.yml)可以写遇到的问题、实际尝试、效果和局限。短问题或近况用[随便聊聊](https://github.com/Al-LeanMuscle-Club/AI-LeanMuscle-Club/issues/new?template=community-chat.yml)，也欢迎直接回复已有帖子。分享和回复不影响周榜分数。

## 浏览器辅助页

[打卡辅助页](../README.md#member-helper)可以查找自己的打卡帖、生成每天的打卡文字，并查看已发布的周榜。它不会代你发布或索取 GitHub Token。日期默认按设备填写，请确认与打卡帖时区一致。

在本地预览时，于仓库目录运行 `python -m http.server 8000`，再打开 `http://localhost:8000/tools/`。托管页面要由维护者先[启用 GitHub Pages](PAGES_QUICKSTART.zh-CN.md)。

## 公开分享范围

所有 Issue、评论和照片都是公开的。选 **No** 只是不上具名榜单，不会隐藏原帖。把当前打卡帖改为 No 或关闭后，下次统计会移除已生成 v3 榜单中的对应行；Git 历史里的旧版本不会消失。

只分享自己愿意公开的内容。体重、健康史、照片、精确位置和保密科研信息都不是参加条件。

旧周计划、饮食记录和 10 分制的迁移说明见[历史功能说明](LEGACY.md)。
