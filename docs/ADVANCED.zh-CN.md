# 可选进阶功能：周计划、记录与参与积分

[English](ADVANCED.md) · [返回社区首页](../README.md)

想按自己的安排记录一周，可以使用下面的工具。随手交流、自由运动和饮食记录都不需要周计划；你可以只使用对自己有帮助的部分。

## 用一份周计划记录这一周

1. [创建周计划](https://github.com/Al-LeanMuscle-Club/AI-LeanMuscle-Club/issues/new?template=weekly-plan.yml)，填写周一日期、时区和现实可行的活动。每人每周一个 Issue；公开排名默认选择 **No**。
2. 运动后在自己的计划下评论，记录实际完成情况。也可以用[成员辅助页](../README.md#member-helper)准备文字。
3. 周末以 `/review` 开头写几句感受、遇到的困难和下周调整。没有完成的一周也可以复盘。

下面是格式示例，不代表真实打卡或训练处方：

```text
S1 | Tuesday | strength | 自己选择的训练 | 自己选择的忙周替代方案
S2 | Thursday | basketball | 和朋友练球
```

每行依次为 `编号 | 完整英文星期 | 运动项目 | 内容 | 可选替代方案`，编号使用互不重复的 `S1`–`S99`。Active 计划包含 1–14 次活动；旧版三列格式继续兼容。描述和复盘可以用中文。

运动项目、个人目标和本周科研节奏可以分别选择，不要求一个人只练一种运动。[完整字段与分类说明](MEMBER_GUIDE.zh-CN.md#1-按本周科研安排制定计划)

## 记录完成情况

每条评论只放一个命令，日期使用计划所填时区中的实际活动日期：

| 命令示例 | 含义 |
| --- | --- |
| `/done S1 2026-10-27` | 完成 S1 的原计划 |
| `/fallback S1 2026-10-27` | 完成 S1 第五列中提前声明的替代方案 |
| `/partial S1 2026-10-27` | 完成了一部分，获得半次执行额度 |
| `/skip S1 2026-10-27` | 保留跳过的记录，不获得执行分 |
| `/meal 2026-10-27` | 记录一餐，不加分 |

同一活动只计一次，使用最新有效状态；备注和照片选填。首次成功同步会确认本周计分活动，之后删除未完成项目不会提高积分，新增活动仍可记录。[命令、日期和纠错细节](MEMBER_GUIDE.zh-CN.md#2-用简短评论记录训练)

## 自愿参与每周积分

| 项目 | 最高积分 |
| --- | ---: |
| 一个有效的 Active 周计划 | 1 |
| 个人执行：`6 ×（完成次数 + 0.5 × 部分完成次数）/ 已确认计划次数`，保留两位小数 | 6 |
| 非空的 `/review`，与完成情况无关 | 2 |
| 经维护者审核的经验贡献 | 1 |
| **每周上限** | **10** |

完整完成和预设替代方案均计一次执行额度。积分按周重置，同分并列；运动量、体重、热量、照片或发帖数量不额外加分。选择 Recovery，或本人评论 `/pause`，即可退出该周排名；暂停会持续到编辑或删除该评论为止。

经验分享不必申请积分；需要申请时，审批须匹配作者、所属周和完整正文，单独添加标签不足以计分。[完整计分与纠错规则](SCORING.md) · [虚构演示榜](../examples/demo-board.md)

选择 **No** 只是不进入生成的具名榜单，原始 Issue、评论和照片仍然公开。详细身体数据、饮食数据和照片始终选填。[公开范围说明](MEMBER_GUIDE.zh-CN.md#公开分享范围)

## 回顾、复用与工具
