# 从喜欢的运动开始，把运动变成生活的一部分

**原作者：[@rentainhe](https://github.com/rentainhe)** · 分享日期：2026-10-24

原帖：[《减肥30kg的经验分享》· Issue #35](https://github.com/Al-LeanMuscle-Club/AI-LeanMuscle-Club/issues/35)

本文是原帖的编辑摘要，记录作者如何从喜欢的运动出发，逐渐把运动融入日常。完整经历与后续补充见原帖。

## 经历中的几个转变

1. **从自己喜欢的运动开始。** 篮球带来的乐趣让他有动力继续参与。他认为，一开始要求过高会让坚持更困难。
2. **逐步了解饮食和训练。** 后来，他开始关注食物的热量与营养构成，并加入力量训练。
3. **把习惯放进日常生活。** 他逐渐调整早餐、作息和训练安排，也从搭子的相互督促中获得支持。
4. **拉长观察的时间。** 后期，他更重视体态、体能和长期保持，关注点不再只有体重数字。

## 科研之外，给运动留一点时间

作者还提到利用 Agent 工作的间隙运动。可以继续聊聊：在各自的科研节奏里，怎样安排自己喜欢、愿意重复的活动？

这里整理的是个人经历；原帖中的具体训练频率、饮食安排和效果判断保留在原文中，不作为俱乐部统一推荐的方案。
