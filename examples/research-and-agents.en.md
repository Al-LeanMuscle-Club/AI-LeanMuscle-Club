## Example 1: Organizing public experiment results into a table

**Title:** [Research / Agent] Using an Agent to organize public experiment results: how much time was actually saved?

**Task and workflow**
Fictional member Lin asks an Agent to organize experiment-result files that Lin is allowed to share publicly into a summary table, then checks it manually.

**Checking and rework**
Similar tasks previously took about 40 minutes of manual work. This time, writing clear instructions takes 5 minutes, and checking and corrections take 15 minutes. Waiting for the Agent to run is recorded separately rather than counted as manual work.

**Outcome and limits**
The estimated net time saved in this example is about 20 minutes, of which 10 minutes are used to go out for a walk. This describes only this observation; other tasks are not guaranteed to save the same amount of time. No private experiment data is uploaded.

## Example 2: An attempt that did not save time

**Title:** [Research / Agent] Automated literature organization was no faster than doing it manually: recording why

**Task and workflow**
Fictional member Zhou tries using an Agent to assign topic labels to public papers.

**Checking and rework**
Several papers receive unsuitable labels. The time spent checking and regrouping them offsets the initial savings.

**Outcome and limits**
There is no reliable figure for net time saved in this attempt. Next time, establish the category boundaries using a small sample before deciding whether to process the full set. Sharing checking methods is welcome; model output should not be treated as a verified conclusion.
