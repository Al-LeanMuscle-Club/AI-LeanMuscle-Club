Keep it simple.

Fallback completion needs an alternative already declared for that session. Partial and skipped sessions earn no execution points. Meal records are optional and earn no extra points; model estimates are estimates, not a health score.

This page runs on GitHub Pages or a local web server. GitHub's code viewer does not execute HTML; use the deployed Pages URL, or download the repository and run python -m http.server 8000, then open http://localhost:8000/tools/.

There is no sign-in, saved credential, automatic submission, or connected food-analysis model here. Clipboard actions and drafts stay in your browser. The report view fetches this site's generated public report.
