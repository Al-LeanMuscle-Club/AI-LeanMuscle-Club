05 / 交流与搭子

分享一个别人也能试试的办法

新人报到与训练记录随手记一次运动，或用小计划记录中断与重新开始。餐食与忙周安排食堂搭配、出差吃饭、快手菜与真实感受。找运动搭子写清地点、时间、项目和对参与者的期待。科研与 Agent 工作流分享实际用过的方法、效果和适用条件。
前往 Issues 发起交流 ↗先看交流示例

社区交流统一使用 Issue，无需周计划且不计分。示例内容为虚构演示，不代表真实成员记录；可以参考格式，再填写自己的实际内容。

06 / 下一周

沿用上周计划，按情况调整

粘贴原计划的 Markdown 正文，生成下周本地草稿。公开榜单选项会重置为 No；训练勾选状态不会沿用，请检查日程和旧的个人信息。

到 GitHub 周计划表单中填写检查后的字段。旧评论和打卡记录不会被带到下一周。

命令行方式

在仓库目录生成本地草稿：

python scripts/member_tools.py carry --issue 123 --week 2026-11-02 --output draft.md

真实记录，按自己的节奏。

照片、体重、热量和营养数据都不是参加条件。可选估算请注明来源和不确定之处；这里没有自动食物识别或营养评分。

此页面无需登录，不保存凭据，也不会自动发帖。草稿和复制操作留在浏览器。这里展示最近一次发布的报告；周报更新后，网站完成发布才会显示新内容。

本地预览说明

GitHub 代码页面不会执行 HTML。请打开部署后的 Pages 地址，或在仓库目录运行 python -m http.server 8000，再打开 http://localhost:8000/tools/。
