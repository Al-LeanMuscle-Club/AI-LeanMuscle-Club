# 每周运动复盘

## 输入
成员自愿提供的周计划、打卡状态和非敏感感受；如需读取已有公开 Issue，只读取所需来源，勿扩大转载范围。

## 步骤
1. 区分计划、真实记录、未报告、部分完成和 Recovery。
2. 不把未打卡当作“没有运动”，不根据照片或自由文本伪造命令与积分。
3. 概括本周可行的安排、遇到的时间冲突、适合下一周的轻量调整。
4. 若用户确认是其周计划 Issue，输出以单独一行 `/review` 开头的评论草稿；否则输出普通文字复盘。
5. 明确草稿尚未发布，成员自行确认；排行榜分数只能引用报告 JSON 和 `docs/SCORING.md`。

## 推荐输出
```text
/review
这周的实际完成情况：……
遇到的困难：……
下周想调整：……
```

## 边界
不比较体型、不提供医疗诊断、不声称运动促进了科研成绩、不自动发通知、不读取微信群或其他私人聊天。
