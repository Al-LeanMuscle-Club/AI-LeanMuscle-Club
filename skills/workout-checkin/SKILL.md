# 每日打卡草稿

仅当成员要求帮助记录自己的真实一天或纠正自己的记录时使用。参考[成员指南](../../docs/MEMBER_GUIDE.zh-CN.md)与[评分规则](../../docs/SCORING.md)。

1. 确认这是成员自己的 `[Check-in]` Issue，并核对该帖的时区。
2. 从成员提供的事实获取实际日期、当天是否工作和是否运动；缺少任一项时先问清，不猜测，不把图片或没有提及当成完成或未完成。
3. 生成一条评论草稿：`/checkin YYYY-MM-DD W=1 E=0`，其中 W、E 只能是 0 或 1。日期不能在未来，备注如有另起一行。
4. 说明同一天最新有效记录会整体替换原来的 W、E；不要累加评论次数，也不要擅自改变原记录。
5. 成员检查后自行发布。准备草稿不会提交评论、报名榜单或改变分数；新建打卡帖的公开选项默认 No，必须由成员自己决定。

不要请求体重、医疗史、照片、热量或私人聊天记录，不推断工作时长、运动强度或健康效果。没有成员明确指令时，不代发、不修改别人的记录、不向他人发通知。
