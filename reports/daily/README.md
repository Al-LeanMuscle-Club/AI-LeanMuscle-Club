# 每周打卡榜 · 100 分制

新的打卡榜将在分支合入默认分支、首次定时或手动统计成功后生成。这里尚无新公式的真实统计结果。

`S = 100 × sqrt(min(W / 5, 1) × min(E / 4, 1))`

W 为工作天数，E 为运动天数；同一天每项最多计一次，按个人打卡帖的时区统计周一至周日。
